⏱️ Auto-lock admin

Owner mode locks itself after inactivity or when the app is backgrounded, so a walked-away device does not stay unlocked. Raises the bar against a hands-on staffer; it is not tamper-proof on a shared device.

🔒 Lock app at launch

When on, the app asks for the Admin PIN once every time it starts. It uses the same Admin PIN — there is no separate password, so if the PIN is forgotten the app cannot be opened until the app data is reset. Unlocking only opens the app; it does not switch the device into Owner mode.

📤 Export control

File and bulk-data exports are off by default. When enabled, every CSV, PDF, ZIP, backup and print still requires a fresh Admin PIN approval. The permanent register stores only action codes, time, user, format, scope and counts — never filenames, customer details or salary values.

🛡️ Production-device hardening

Use production mode only on a dedicated, non-rooted release device. Debug/root warnings remain visible; unsafe production devices cannot open Payroll/Tax or export data.
