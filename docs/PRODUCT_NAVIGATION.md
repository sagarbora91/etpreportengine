# Product Navigation

Version 1.6.0 presents eight top-level areas for a Store Manager:

| Area | Routine purpose |
|---|---|
| Home | Business-date readiness, missing sources/manual inputs, controls, report generation and finalisation. |
| Import | Manual/bulk ETP import plus the Source Inbox for retained workbook, PDF and image evidence. |
| Reports | One filter/preview/export workflow across sales, stock, staff, tender, service and exceptions. |
| Registers | Audited operational registers linked to immutable documents. |
| Accounting | Balanced accounting preparation from final report generations and approved mappings. |
| Archive | Immutable generation browse, comparison, Excel/PDF/ZIP export, email draft and WhatsApp initiation. |
| Control Centre | Issues, conflicts, approvals, global investigation, automation, backup and recovery. |
| Admin / Settings | Owner-only users, masters, KPI catalogue, integration health and SQL configuration. |

The daily path is `Import → Check → Complete inputs → Generate → Review exceptions → Finalise → Share`. Technical hashes and migration details remain stored and auditable without dominating routine screens.
