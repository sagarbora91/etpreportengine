# Phase 2 Productisation Gap Map

Audit date: 26 August 2026. Baseline: v1.5.0.

| Work package | Baseline | v1.6.0 result |
|---|---|---|
| UX | Partial | Eight-area navigation, Home cockpit, unified Reports Centre terminology and plain-language product actions. |
| Import/data operations | Partial | Existing batch/cancel/retry plus Source Inbox and row-level overlap classification/conflict routing. |
| Documents/registers | Missing | Immutable repository, native-text/OCR abstraction, optional Paddle helper, human verify/reject queue and generic audited registers. |
| Distribution | Partial | Existing archive plus hashed ZIP manifest, safe WhatsApp initiation, attached email drafts and an Owner-managed sharing address book. |
| Governance | Partial | Existing roles/masters plus approvals, KPI catalogue, import conflicts, product health and global investigation. |
| Accounting | Missing | Approved effective mappings, balanced batch composer, review/approval storage and one-way Tally XML export. |
| Automation/management | Built/partial | Watch folder expanded to documents; conflict dates block auto-pack; existing scheduler/backup/health retained. |

External activation items are limited to a packaged PaddleOCR helper/model, real accounting ledger/tax mappings, exact Tally company name/environment, optional SMTP credentials in approved Windows credential storage and a code-signing certificate. These do not block core offline reporting.
