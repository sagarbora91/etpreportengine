# Visual report catalogue

| Report | KPI focus | Primary visual | Control context |
|---|---|---|---|
| Daily Sales / DSR | TY sales, LY sales, units, invoices | daily line/bar analysis | canonical sales policy |
| Brand Sales | sales, units, returns | top brands + Other | source-signed returns |
| Closing Stock | quantity, cost, items | stock category bars | immutable snapshot |
| Staff Performance | sales, units, invoices | staff ranking bars | unmatched enrichment |
| Tender Reconciliation | invoice, tender, variance | clustered comparison | technical reconciliation status |
| Management Trend | sales, units, invoices, variance | time trend | unchanged daily controls |
| Daily Exceptions | count and measurable variance | exception severity/area bars | exact evidence pointers |

Every report includes the original detailed table. Excel adds Executive Summary, Charts & Analysis, Detailed Data, Controls & Exceptions, and Metadata. PDF begins with a visual management summary and then paginates the detail.
