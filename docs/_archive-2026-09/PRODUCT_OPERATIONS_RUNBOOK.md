# Product Operations Runbook

## Morning workflow

1. Open Home and select the prior business date/store.
2. Review source completeness and open issues.
3. Import files or confirm watch-folder outcomes in Source Inbox.
4. Complete only required manual inputs and physical counts.
5. Generate and preview the pack. Failed controls remain visible.
6. Finalise only when eligible.
7. Open Archive, select the final generation, export ZIP and initiate email/WhatsApp sharing.

## Document/register workflow

Add the PDF/image in Import, confirm extraction status, verify important fields, then create the linked Inward Register entry. OCR failure does not affect ETP reporting.

## Conflict workflow

Open Control Centre, inspect the business identity and hashes, acknowledge the issue, request restatement approval, reopen a locked date if required, import the corrected source in restatement mode and generate a new immutable report generation. Never edit canonical rows.

## Accounting workflow

Owner approves effective ledger mappings. A Store Manager previews and saves a balanced batch from a final report. Owner reviews, approves and exports Tally XML. Back up the Tally company, import transactions, review Tally exceptions/Day Book and record any reference.

## Recovery and support

Daily checksum backups and monthly isolated recovery drills remain scheduled. Control Centre shows backup age/free space and permits Owner-run backup/recovery checks. Create a privacy-safe support package before investigation. Business data/backups are retained indefinitely; audit history is retained for two years.
