# Import Failure Register

Every ETP import that is not "drop the folder in, press one button, correct numbers" gets one row here. Rows are appended by the `etp-import-failure` skill or the `etp-import-triage` agent; status is changed only by Claude during a phase audit. Codex reads this file at the start of every phase and must close every OPEN row mapped to that phase or state why it is deferred.

Categories: layout-drift · consolidation-artefact · data-content · importer-bug · ux-friction · unsupported-report.
Status: OPEN · FIXED (phase N, commit) · VERIFIED (Claude audit) · DEFERRED (reason) · WONTFIX (reason).
