| LF-01 — PDF details lost content | The old fixed-width PDF table truncated headers/values/notes and omitted totals; 52 of 56 non-DSR cases failed content comparison. | LF-02 — PDF charts misrepresented signs and omitted the Other bucket | The old renderer drew the absolute value upward and selected only ten points, omitting the composer's additional Other point. Financial composition/calculations were not changed. |
| LF-03 — late export status overwrote a newer report | Excel/PDF completion and failure unconditionally changed the current report status. The extracted completion handler captures the report and revision, prevents duplicate export starts, and updates visible status only for that revision. | LF-04 — saved file reported as export failure | Activity-history failure after a successful file write was caught as though the file export failed. It now says the file was saved and history could not be updated. | Injected post-save history failure passes; no false export-failure message. |
